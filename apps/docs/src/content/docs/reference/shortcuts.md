---
title: Keyboard shortcuts
description: Desktop app shortcuts.
---

<kbd>Ctrl</kbd> or <kbd>⌘</kbd>.

| Keys | |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Send; submit a dialog |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | New request |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Duplicate |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Jump to request |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Open folder |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Variables |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | Bots |
| <kbd>Ctrl</kbd>+<kbd>G</kbd> | Git changes |
| <kbd>Ctrl</kbd>+<kbd>J</kbd> | Toggle response |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Settings |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Undo / redo in the flow editor |
